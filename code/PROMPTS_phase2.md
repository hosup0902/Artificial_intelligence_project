# 프롬프트 기록 — Phase 2 (양팔 + 분해 공구, 최종 버전)

과제 안내문: "LLM을 사용하는 경우, 사용한 모델과 버전, 프롬프트, 생성된 코드를 제출합니다."

- 모델·도구: Phase 1(`PROMPTS_phase1.md` 머리말)과 같은 Claude 모델, **Claude Code** (클라우드 원격 세션, Linux 컨테이너).
- 세션: Claude Code on the web, 브랜치 `claude/beautiful-gates-6udr26` (2026-11-05 ~ 11-06).
- 방식: 여러 턴의 대화. Claude가 코드를 작성·실행하고, 시뮬레이션 로그·접촉력·렌더링을 보며 스스로 원인을 찾아 고쳤다.
  사용자는 목표와 방향만 지시했다. 평가는 코드를 고정한 채 같은 seed로 수행했고, 평가 중 LLM 호출은 없다(결정적·재현 가능).
- 생성된 코드: `code/` 전체 (Phase 1 코드를 바탕으로 `battery_sim/` 전부와 실행 스크립트를 다시 작성).
- 진행 기록: 저장소 루트 `PROGRESS.md`(작업 로그), `REPORT_MATERIAL.md`(설계·실패 분석 정리).
