# Mid-term (single-arm) experiment scripts — legacy

These scripts belong to the mid-term design (one SO-101, cells released by pushing them into the springs
so that their + ends popped up on a floor rib). That pop-up mechanism has been removed: the compartment
now behaves like a real one and the cells must be pried out with the tool. The scripts are kept for
reference only and do not run against the current `battery_sim` package.

Current equivalents: `../ablation.py` (control experiments), `../dev_tools/retention_test.py`
(upside-down retention check), `../dev_tools/dbg_pry.py` (pry skill debugging).
